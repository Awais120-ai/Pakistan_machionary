# Pakistan_machionary

Website for **Pakistan HMTC** (Pakistan Heavy Machinery Training Center).

## Pages

- Home
- Our Trainings
- Get Certificate
- About Us
- Contact Us
- Blog

## Run locally

Open `index.html` in a browser, or from this folder:

```bash
python -m http.server 5173
```

Then visit http://127.0.0.1:5173/
